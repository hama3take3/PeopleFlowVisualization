# PeopleFlow Viz — 人流 × 街3Dモデル 可視化ツール

まちづくりワークショップで、市民・行政・デベロッパー・来街者など多様なステイクホルダーが
**同じ街の「現状」を共通認識として持てる**ようにするための、人流可視化Webアプリです。

街の3Dモデル（BIM含む）の上に、属性を持った歩行者（人流）を3Dで重ね、
時刻や時間の速さを操作しながら、街の使われ方をその場で観察・対話できます。

> 人流データは現状ダミー（1日あたり約500人）です。将来的にLiDARやAgoop等の実データへの差し替えを想定しています。

---

## なぜ作るのか（Why）

まちづくりの現場には様々なステイクホルダーがいますが、対象となる街の認識がそれぞれ異なるため
意見がまとまりづらいという課題があります。共通認識としての「現状」を分かりやすく示すことで、
議論の土台を揃えることを狙います。

## 誰が・いつ使うのか（Who & When）

まちづくりワークショップなどの場で、市民・行政・デベロッパー・来街者などが利用します。

## 何ができるのか（What）

- 街の3Dモデル上に人流を3D可視化
- **glTF / GLB / PLY / FBX / OBJ** の3Dモデル・BIMをインポート
  （[map.fleet.im](https://map.fleet.im/) などからダウンロードしたモデルも読み込み可）
- 人流はダミーデータ（既定で約500人分）。属性付きのスケジュールで街を移動
- **時刻スライダー**で時間帯を切り替え（00:00〜23:59）
- **時間の速さスライダー**でシミュレーション速度を調整（停止〜×600）
- 歩行者に**マウスを合わせると属性**（性別・年代・障害の有無・状態）を表示
- 人流は**ローポリのアバター10種**（属性に対応）で表現
- アバターを**クリックすると一人称視点**で街の移動を体験
- **右クリックで俯瞰視点**に戻る
- アバターは**街のメッシュと衝突判定**を行い、建物を貫通せず目的地に到達
- 目的地は読み込んだ3Dモデルに合わせて自動割り当て
- マウス操作で**視点位置・向き・縮尺**を変更可能
- **太陽（光源）が時刻に連動**して東→天頂→西へ移動。朝夕は暖色、夜は暗くなる
- **街灯を自動配置**し、暗さに応じて自動点灯・消灯（夕方〜明け方）。夜間も見やすい明るさを確保
- **ストリートファニチャー**（ベンチ・テーブル・パラソル）を地面に配置／右クリックで撤去。
  設置すると時々歩行者が座り、ランダムな時間休憩する
- 歩行者は実寸の歩行速度（成人 ≒ 4.5km/h）で移動
- **地面を持たないモデル**を読み込んだ場合は自動で地面（床面）を追加

## セットアップ

必要環境: Node.js 18+（開発・確認は Node 22 で実施）

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバ起動 → 表示されたURL（既定 http://localhost:5173）を開く
```

本番ビルド:

```bash
npm run build    # dist/ に出力
npm run preview  # ビルド結果をプレビュー
```

## 使い方

### カメラ操作（俯瞰視点）

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 視点の回転 |
| 右ドラッグ / 2本指 | 平行移動（パン） |
| マウスホイール | 拡大・縮小（縮尺） |

### 人流の操作・観察

- **ホバー**：歩行者にマウスを合わせると属性ツールチップを表示
- **クリック**：その歩行者の**一人称視点**へ。街の中を歩く体験ができます
- **右クリック**：俯瞰視点に戻る
- 一人称視点中は **WASD / 矢印キー**で自分で歩くことも可能（建物との衝突判定あり）。
  左ドラッグで視線を周囲に向けられます

### 時間のコントロール（画面下部）

- **時刻**スライダー：見たい時間帯へジャンプ（歩行者が当該時刻の配置に再配置されます）
- **時間の速さ**スライダー：シミュレーション速度（×0で一時停止〜×600で高速）
- ▶/⏸ ボタン：再生・一時停止

### 3Dモデルの読み込み

- 右上「モデルを読み込む」から glTF / GLB / PLY / FBX / OBJ を選択
- 「サンプルの街を生成」で内蔵のグリッド市街地を生成
- モデルは自動で接地され、衝突メッシュ・目的地・街灯が自動構築されます
- **地面を持たないモデル**の場合は、歩行可能面として地面を自動追加します

> [map.fleet.im](https://map.fleet.im/) などから街・BIMのモデル（glTF/GLB等）を
> ダウンロードしてそのまま読み込めます。

### ストリートファニチャー

- 右上「ストリートファニチャー」で **ベンチ / テーブル / パラソル** を選択 → **地面をクリックで配置**
- 配置物を**右クリックで撤去**（一人称中の右クリックは俯瞰復帰が優先）
- **Esc** で配置モード解除
- 設置すると、近くの歩行者が**時々座って休憩**し、ランダムな時間で席を立ちます

### 太陽・街灯（時刻連動）

- 時刻スライダーに連動して太陽（平行光源）が移動します（6:00=東の地平線、12:00=天頂、18:00=西）
- 朝夕は暖色の光、夜は暗い空と弱い光になり、街の時間帯の雰囲気を再現します
- 街灯を自動配置し、**暗さに応じて自動点灯・消灯**します（おおむね 17時頃〜7時頃に点灯）。
  夜間は環境光も底上げして見やすさを確保しています

### 表示オプション

- 移動経路を表示 / 目的地を表示
- **衝突メッシュを表示**：単純な直方体(AABB)ではなく、実際に衝突判定へ使っている
  メッシュ形状そのものを赤いワイヤフレームで重ね表示
- 属性フィルタ（凡例）：項目をクリックして属性ごとに表示/非表示

## アバター（属性10種）

人口構成を模した出現比率で、属性に応じた10種のローポリ・アバターを配置します。

1. 成人男性 / 2. 成人女性 / 3. 高齢男性（杖） / 4. 高齢女性（杖） /
5. 男児 / 6. 女児 / 7. 車椅子利用者 / 8. 視覚障害者（白杖） /
9. ベビーカー利用 / 10. 来街者（観光・リュック）

## 技術構成・設計

- **Three.js** によるレンダリング、**Vite** によるビルド
- **three-mesh-bvh** で街メッシュへの高速レイキャストを実現し、500体規模の衝突判定を毎フレーム処理

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | シーン構築・カメラ（俯瞰/一人称）・入力・UI配線・メインループ |
| `src/CityModel.js` | モデル読込（glTF/GLB/PLY/FBX/OBJ）・実寸保持/接地・衝突メッシュ抽出・地面/目的地算出 |
| `src/Crowd.js` | 人流シミュレーション（スケジュール移動・衝突回避ステアリング・属性） |
| `src/AvatarFactory.js` | 属性別ローポリ・アバター10種の生成と歩行アニメーション |
| `src/Furniture.js` | ストリートファニチャー（ベンチ/テーブル/パラソル）の生成・配置・撤去・座席管理 |

### 衝突判定と経路

- 各歩行者は前方・左右のレイキャスト（ウィスカー）で建物を検出し、空いている側へ回避ステアリング
- 判定は AABB（直方体）ではなく、読み込んだ**実メッシュのジオメトリに対して**行います
- 移動直前にも進入チェックを行い、壁にめり込む場合はスライド／停止することで**建物を貫通しません**
- 目的地は読み込んだモデルの建物周辺をサンプリングして自動生成し、スケジュールに沿って巡回します

### 縮尺（人と建物のスケール）

- 歩行者アバターは実寸（成人で全高 約1.7m）でモデリング
- 読み込んだ街モデルは原則**実寸（メートル）のまま**配置し、人と建物の縮尺を一致させます
  （FBXは慣習的にcm単位のため自動でメートル換算。極端に大小なモデルのみ穏やかに補正）

### 時間モデル

- シミュレーション時刻（分）を実時間×速度倍率で進行
- 各歩行者は1日のスケジュール（通勤・買い物・通学・観光・散歩など）に基づき目的地を移動
- 時刻スライダーでのスクラブ時は、その時刻に応じた位置へ歩行者を再配置

## 既知の制約・今後の展望

- 人流は現状ダミーデータ。今後 **LiDAR / Agoop 等の実データ**取り込みに対応予定
- 経路は簡易ステアリングによる回避（厳密なナビメッシュ経路探索は未実装）
- 大規模・高ポリゴンなモデルでは描画負荷に応じて人数調整を推奨
